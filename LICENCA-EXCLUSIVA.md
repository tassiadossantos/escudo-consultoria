## CLÁUSULA 1 — DO OBJETO

1.1 O presente contrato tem por objeto a concessão de **Licença de Uso Exclusiva** do software proprietário denominado **"Escudo Consultoria — Plataforma SST"**, compreendendo:

   a) **Frontend:** Aplicação web desenvolvida em React + Vite + Tailwind CSS, incluindo calculadora de multas, blog, checklist e demais funcionalidades de conversão e educação de mercado.

   b) **Backend/API:** API RESTful desenvolvida em Express + TypeScript + Drizzle ORM, com persistência em PostgreSQL (Supabase), incluindo autenticação JWT (RS256), middlewares de segurança (CORS, Helmet), telemetria e integrações.
